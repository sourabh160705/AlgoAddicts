# Requirement traceability

- Data ingestion: DuckDB/Polars pipeline for the supplied CSV.
- Mule analytics: velocity, fan-in, fan-out and terminal indicators.
- Risk score: explainable 0–100 weighted signals.
- Graph: up to four downstream hops.
- UI: interactive Cytoscape graph and trace table.
- Evidence: generated from verified database rows.
- AI guardrail: local LLM does not author factual identifiers.
- Reports: draft case diary and bank freeze requisition.
- Offline core: no cloud DB or cloud inference is required by the application.

The official performance targets remain to be measured on the real challenge dataset/hardware.
